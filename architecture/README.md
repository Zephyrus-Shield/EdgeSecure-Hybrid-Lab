# EdgeSecure Hybrid Infrastructure Architecture

## Overview

This directory contains the architectural overview of the EdgeSecure Hybrid Infrastructure Lab.

Unlike the detailed engineering manuals located in the `/docs` directory, these documents provide concise system-level explanations of the infrastructure, component interactions, traffic flow, and security model.

The objective is to allow readers, recruiters, engineers, and collaborators to understand the overall design before diving into implementation details.
